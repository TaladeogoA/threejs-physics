# Three.js Physics - Learning Project

This repository is part of my "Three.js Journey" and focuses on exploring physics integrations in 3D web environments. It is a dedicated learning project used to experiment with Three.js and Cannon.js.

## Setup

Download [Node.js](https://nodejs.org/en/download/).
Run the following commands:

```bash
# Install dependencies (only the first time)
npm install

# Run the local server at localhost:8080
npm run dev

# Build for production in the dist/ directory
npm run build
```
